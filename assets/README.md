# NetVeil — Logo Asset Pack

Mark: **A · Stroke V** · Wordmark: **Rajdhani SemiBold** (split — "Net" light, "Veil" violet→magenta gradient).

## /svg  (vector — scale to any size, fully transparent)
- `netveil-mark.svg` — the V mark, gradient, transparent bg
- `netveil-mark-white.svg` — single-color white (for dark backgrounds)
- `netveil-mark-black.svg` — single-color black (for light backgrounds)
- `netveil-app-icon-dark.svg` — rounded-square app icon, dark tile (primary)
- `netveil-app-icon-gradient.svg` — rounded-square app icon, gradient tile
- `netveil-lockup-horizontal.svg` — icon + wordmark, for dark backgrounds
- `netveil-lockup-horizontal-light.svg` — same, dark text for light backgrounds
- `netveil-lockup-stacked.svg` — icon over wordmark
- `netveil-wordmark.svg` — wordmark only
  (All lockup/wordmark SVGs have the Rajdhani type converted to **vector outlines** — fully self-contained, no font needed.)

## /png  (raster, on the brand dark #0B0A12; icons/marks are transparent)
- `favicon-16/32/48/64.png` — favicons (hold down to 16px)
- `apple-touch-icon-180.png`
- `app-icon-dark-256/512/1024.png` — app icon, dark tile
- `app-icon-gradient-512/1024.png` — app icon, gradient tile
- `netveil-mark-512/1024.png`, `netveil-mark-white-512.png` — transparent mark

Lockups & wordmark come two ways:
- **Transparent** (primary, for dark surfaces — "Net" is light): `netveil-lockup-horizontal.png`, `netveil-lockup-stacked.png`, `netveil-wordmark.png`
- **On brand dark** `#0B0A12`: `netveil-lockup-horizontal-on-dark.png`, `netveil-lockup-stacked-on-dark.png`, `netveil-wordmark-on-dark.png`
- For **light** backgrounds use `svg/netveil-lockup-horizontal-light.svg` (dark "Net").

## Color
Ink `#0B0A12` · Surface `#13111D` · Violet `#8B3DF5` · Magenta `#B14BF4` · Lift `#D173FF` · Text `#ECEAF6`
Signature gradient: 135°, `#5A1FB0 → #8B3DF5 → #D173FF`

## Clear space & minimum size
Keep clear space ≥ the height of the V on all sides. Icon reads cleanly down to 16px.
